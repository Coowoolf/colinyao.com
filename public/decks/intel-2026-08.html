盯发货，别盯发布会

叙事在天上 · 位移在运行时控件和价卡上

一句话总判：8 月的表面剧情是「全双工大官宣」——GPT-Live 架构文（8/3）、SeedRealtime（8/5）；但到月末，全双工族在可采购的 API 层一单未发。真正落进开发者手里的是三样便宜东西：轮次控制权下放（Deepgram ForceEndTurn、Bland 自适应接话）、TTS 换代与私有化（Sonic-3.6 GA、Flux self-host+FIPS）、定价透明化（NICE 从 Price on Application 转明码五档）。
本卷合成自 8 月全月竞品监测序列；判断与事实分段标注——标【事实】的只汇编带来源锚的内容，标【判断】的欢迎挑战，挑战入口就是推翻它挂的事实。

02 · 位移一 · 全双工是叙事层，运行时控件才是发货层

轮次控制权，正在下放给应用

模型侧的全双工还在官宣期，但「谁决定什么时候接话」这件事，这个月实实在在换了主人——从模型层交到了应用层手里。前半月拆的是模型侧回合制，后半月把拆下来的控制权交给了集成方。

8/3 · Bland
自适应接话
按来电者语速与停顿调整接话时机，pace 变化随之匹配——打断体验第一次成为厂商级可调项。
8/28 · Deepgram Flux
ForceEndTurn
轮次三模式（Automatic / Semi-manual / Fully manual）＋ eot_threshold=1.0 热切换——EOT 判定权整体交给应用，可 BYO-VAD、可按键说话。
8/27 · Daily/Pipecat
PhoneLLM Alpha 1
开源电话 LLM＋自建 PhoneBench，自报对旗舰 API「94% cheaper」。Alpha 非 GA；$0.00025/agent-min 是自托管测算不是价目。
【判断】对标材料里，全双工族只能写「叙事基准」；供给对比表继续以现售 API 为准。真正在改变集成方行为的是轮次控制权下放——电话 Agent 的打断参数面（ForceEndTurn 类）应进能力对比的固定列：它已经是可采购差异。
源：各厂官方 changelog / 博客（页面带日期）INTERNAL
03 · 位移二 · 定价面从「不透明」向「明码」挪了一格

NICE：从「请询价」到明码五档

【判断】位移窗口 ≤2026-08-26（两次读数间隔小时级，精确改价日未考）。CCaaS 头部从报价制转明码通常是竞价压力信号——与 Genesys / Talkdesk / Five9 全部明码同台后，「不给价」在采购短名单里开始变成劣势。坐席订阅带 $110–249 首次可全公开锚定，我方市场空间测算里「坐席替代」镜头的价格锚由此站稳。
同月定价面的其它动静：AWS 定价页重构（费率移入 appendix、区域标注缺失）、Zoom 价页链接失效——公开价卡本身处在变动期，任何采购对比须以当日打开的页面为准，引用旧截图会踩空。

04 · 位移三 · STT/TTS 运行时进入「采购门槛」竞争

胜负手不在 WER，在实体、端点与部署形态

Google · 8/26
Gemini 3.5 Transcribe
进实时转写（流式自报 sub-second）；生态句点名 LiveKit / Pipecat / Agora。博客写 public preview、changelog 写 GA——两套官方口径并列不洗。页内无定价。
Cartesia · 8/27
Sonic-3.6 GA
自报 <90ms 首包；对 Eleven v3 盲测偏好 92% 系厂商自测。生产须手动改模型 ID——3.5 流量不会自动切。前半月同族：Ink-2 keyterm（8/11）。
Deepgram · 8/26
Flux TTS self-host GA
私有化部署＋ FIPS 140-3 镜像——这是拿政企/合规单的门槛牌，不是体验牌。同厂三天连发（8/26 TTS / 8/27 语言包 / 8/28 轮次控件），本月最密单厂动作。
【判断】STT 的竞争维度继续从「谁听得准」移向「谁交出实体、端点和轮次的控制权」；TTS 从音质进入部署形态。附带一条：Google 点名的三家编排层里有 Agora——我方第一次被写进超一线厂商的产品日生态句。性质是「被列为可集成生态」，非合作官宣，勿升格引用。
位移四（并存的另一面）：叙事层热闹——Five9 拿 IDC Agentic CCaaS Leader（8/26）、TTEC 拿 Brandon Hall Gold（8/24），均无新 SKU 无新价，只进叙事台账不进运行时评分；国内层静默——SeedRealtime 之后，思必驰/百应/火山呼叫中心等官网 8 月无带日期发布。静默是「官网低披露习惯＋只采官方一手」的合成结果，不可读成国内无动作；下一个可证伪窗口：IFA（9/4–8）与华为全联接（9/17–19）。

06 · 怎么读这份材料 · 边界先说清

四条阅读护栏

①两套计数「24」与「13」生成方式不同（单日集中回补 vs 逐日双源实测），相加没有意义；比较月度密度请分体制看。
②自报不升格所有厂商自测/自报数字（Sonic 92% 盲测偏好、Gemini WER 4.0%/2.6%、PhoneLLM「94% cheaper」等）在本卷始终保持「厂商自报」等级，未经独立复测，引用时须带此限定。
③渠道≠事实部分厂商的日更渠道月内失效（如 ElevenLabs 日 changelog 连续多日 404）——相应厂商的「无动作」是监测渠道受限之上的观测，不是确证的零；国内层同理。
④密度≠实力Deepgram 的三天连发部分反映其 changelog 勤快——渠道可得性在塑造计数，密度信号用于节奏判断，不用于产品力排序。
